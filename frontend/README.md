# BrewDesk Frontend

React and Vite customer storefront and staff dashboard.

From this folder:

```powershell
npm install
npm run dev
```

Keep the backend running at `http://127.0.0.1:5000`. The development proxy forwards `/api` there; uploaded product photos also use this local backend address.

See the root [README](../README.md) for configuration, features, and the full setup guide.
